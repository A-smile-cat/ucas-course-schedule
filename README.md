# 选课排课表（国科大专属）

一个在浏览器本地运行的选课排课工具，核心功能是**自动检测课程时间冲突**：时间冲突的课程不允许排入课表，只能放入候选区，从根本上避免选课时时间撞车。

## 功能特性

- **13 节课 / 天**（时间取自学校课表），周一至周日，共 20 周（第 1 周 2026-08-31 起算）
- **自由排课**：任意添加/删除课程的上课时间（星期 × 节次 × 周次，支持连堂与任意周次组合）
- **自动冲突校验**：同一星期 × 同一节次 × 周次有重叠即视为冲突；冲突课程只能留在候选区
- **候选区**：未排入课表的课程集中管理，冲突的课程会打上冲突角标并说明冲突原因
- **已排课程保护**：编辑已排课程产生冲突时自动打回候选区，课表内永不出现冲突
- **课程分类**：专业核心课 / 专业课 / 学科核心课 / 研讨课 / 实验课 / 实践课 / 公共选修课 / 公共必修课，共 8 大类
- **专业学位课重点显示**：金色描边 + 「学位课」徽章
- **课表字号可调**（12-24px）
- **三种导出方式**：
  1. JSON 数据备份（供系统「导入」恢复）
  2. Excel 总表（所有课程排课一览，便于归档共享）
  3. 各周课表图片（所见即所得的 PNG，可选周次，打包为 zip）
- 数据全部保存在浏览器 localStorage，不上传任何服务器

## 使用方法

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge）。

> 提示：首次打开有示例数据用于演示，可在右上角「清空」后录入自己的课程；正式使用前建议先导出 JSON 备份。
